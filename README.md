# RuNotion Extension

RuNotion - это браузерное расширение для перевода интерфейса Notion на русский язык.

## О проекте
Данный проект предназначен для автоматического перевода пользовательского интерфейса Notion. Он использует `MutationObserver` для отслеживания изменений в DOM-дереве и подмены текстовых элементов и атрибутов на их русские аналоги.
Работает на сайтах Notion и Notion Calendar, Notion Mail переведен не полностью, так как его поддержка заканчивается 22 сентября, 2026.

## Структура проекта
* `content.js` - основной файл скрипта, содержащий логику перевода, обработки HTML-узлов и взаимодействия с Notion.
* `dictionary.js` - словарь перевода, содержащий пары "English phrase": "Русский перевод". Вы можете добавить свои переводы по необходимости, вставив свой перевод в том же формате. Важно идеальное совпадение символов.
* `manifest.json` - файл для работы расширения, использует актуальную третью версию и настроен под Firefox.

## Установка и использование
1. Убедитесь, что у вас установлен браузер с поддержкой расширений (например, Chrome, Firefox, Edge).
2. Загрузите файлы проекта в папку расширения.
3. Загрузите расширение в режиме разработчика в вашем браузере.
